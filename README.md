  Marvel Rivals Meta Analytics Dashboard:


An end-to-end data analytics platform analyzing competitive telemetry, pick rates, win rates, and ban rates across Marvel Rivals roles and rank tiers.


  Key Features:


Hero Meta: Compares current performance metrics across Vanguards, Duelists, and Strategists.


Win Rate vs. Pick Rate: Evaluates hero viability against pick frequency to identify high-performing heroes versus over-picked staples.


Ban Priority: Tracks high-ban targets to isolate heroes defining the current competitive meta.


  Tech Stack:

  
Python, SQLite3, Streamlit, Plotly Express, and Pandas



  What I Learned:

  
To implement SQL queries to isolate meta trends and performance tiers across roles. 


How to translate raw telemetry data into filterable visual distributions.


To recognize when web scrapers hit modern anti-bot barriers and how to pivot to a Seed Script to ingest structured telemetry reliably. 


How to manage virtual environments and dependency workflows.
